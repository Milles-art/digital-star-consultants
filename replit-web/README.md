# Digital Star Consultants Web

A responsive public website for Digital Star Consultants, built from the consultancy project in this repository.

## Included

- Service discovery
- Local request reference prototype
- Request tracking interaction
- Contact details and mobile navigation

## Run locally

From this directory, run pnpm install and then pnpm run dev.

The app is a polished frontend prototype. Request submission and tracking use local browser state until connected to the Laravel API.
